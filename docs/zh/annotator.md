# 语义标注与场景编辑（启动器：Annotator）

本工具用于**语义标注与场景编辑**：把整条赛道按**语义类别**着色渲染——画面里**发白的物体就是还没
分类的 UNKNOWN**，等你去指认。指派结果保存为按赛道生效的规则文件，
游戏画面、语义相机模态与雷达都在秒级内热重载消费它。这就是你教套件
"这条赛道上每个东西是什么"的方式。

需要可选组件 **Semantic annotator**（NVIDIA 显卡）且游戏已进入赛道。
用启动器的 **Annotator** 按钮启动。标题栏常显
`FPS | track / layout | nodes=N | UNKNOWN=M`（英文字面格式）。

## 典型工作流：暂停 → 标注 → 继续

1. 游戏内进赛道，开 bridge，点 **Annotator**。
2. 用启动器的 **Pause** 按钮暂停游戏（物理与声音定格；渲染与数据照常流动，且 WASD
   不会再开车）。用启动器的 Resume 按钮恢复。
3. 自由飞行、U 键巡回 UNKNOWN 物体、面板里指派类别（即时预览变色）。
4. **Save to json…** 落盘——语义图、本工具画面与场景树中对应对象在 1~2 秒内变为新真值色。

## 操作

| 输入 | 功能 |
|---|---|
| 鼠标左 / 右 / 中键 | 平移 / 旋转 / 前进后退；滚轮缩放；`+` / `-` 调飞行速度 |
| WASD / QE（E 升 / Q 降） | 键盘飞行（仅本窗口持焦时有效；Shift ×4 加速） |
| C | 追尾游戏相机开关（开局最佳视角；任何手动操作即脱离） |
| U / Shift+U | 跳到下一个 / 上一个 UNKNOWN 物体 |
| G | 三角网格边线开关 |
| Tab | 显示 / 隐藏场景树面板 |
| 点击物体 | 选中（品红光晕）；点天空 = 清除 |
| 悬停物体 | 青色偏移高亮 + 左下角 `类 名 #下标` 读出 |
| H / Shift+H | 隐藏选中 / 全部显示（把遮挡物藏起来即可选中后面的物体） |
| 树行单击 / 双击 | 选中 / 选中并飞过去 |
| ESC | 退出 |

## 面板（Tab）

- **场景树**：全部场景节点 + 类别色点；`[group]` / `[ghost]` 标签标记
  容器与不渲染的 LOD 壳。
- **过滤**：输入名字子串和/或选类别——只显示匹配行；祖先可展开。
- **UNKNOWN 计数**：`UNKNOWN: N nodes | view X.X%`——你的剩余工作量。
- **选中卡片**：类别下拉 + **Apply**（指派）/ Jump / Clear + 物体的
  世界尺寸。
- **pending 列表**：尚未保存的指派；逐条撤销、`x all` 全撤、
  Re-apply all 重放。

**Apply** 立即把该节点（及**所有同名实例**）换色预览。
**Save to json…** 把全部 pending 指派写成永久规则：

- 默认文件名已替你填好（`<赛道>__<布局>.json` 或 `<赛道>.json`——
  只有这两个名字会被加载）；预览行显示保存后实际加载哪个文件。
- 写盘原子；状态行依次走 `saved → waiting reload → hot-reload confirmed`。
- 在全新赛道上首次保存会以当前全部默认规则为种子建新文件——不会
  有物体因保存瞬间突然变 UNKNOWN。
- 保存位置：`ac_simulator_suite\semantic_annotation\`（面板 `Open
  folder` 小按钮直达）。

## 移除物体（Discard）

- 想移除物体，一般就用右键 **Discard**：物体从游戏画面、相机、雷达和碰撞中全部消失（碰撞变化重进赛道后生效）。
- **LOGIC** 是轻量档，通常无需使用：物体留在游戏画面里，但从相机语义数据与雷达点云中剔除（不影响碰撞体）。

右键树行或选中卡片：`Discard/Restore (single)` 或
`(subtree + LOD family)`——family 档自动连带同名物体的各 LOD 兄弟
（HI/LOW 细节档），通常正是你要的。Ctrl+点击 / Shift+点击 / Ctrl+A
多选后右键整批操作。过滤下拉 "Discarded" 列出当前全部被弃物体——
误删后找回来的主入口。

## 类别表（classes.json）

类别名、颜色、dynamic/exclude 属性都在
`ac_simulator_suite\configs\classes.json`——用启动器的 **Edit
classes.json** 按钮编辑（升级安装不会覆盖你的修改）。改动 1~2 秒热
生效。排除行为的开关在 `semantic_classes.ini`——见
[configs/semantic_classes.md](configs/semantic_classes.md)；规则文件的
格式与回退链见 [annotation-files.md](annotation-files.md)。

## 跟随游戏相机（进阶）

游戏内按 **F7**（游戏自带自由相机——方向键移动、F1 退出），然后在
标注面板勾 **Follow game camera**：工具里飞、游戏画面实时镜像，
反向亦然。再勾 **Game highlight**，选中物体在*游戏画面*里出现同款
品红光晕——用来快速判定"游戏到底画没画这个物体"。

## 注意事项

- **看台观众是粒子系统**——游戏画面与语义相机里有它，但它没有场景
  节点，本工具无法显示或标注；游戏画面与语义图中人群渲染正常、数据不受影响。这是渲染管线的口径差异，不是故障。
- 游戏不画的物体（例如：空气墙）在本工具与雷达里仍然存在
  ——用右键 Discard 把它们移除**，别让它们污染传感器数据。
