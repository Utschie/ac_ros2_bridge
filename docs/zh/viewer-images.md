# 图像查看器（启动器：View Images）

实时查看游戏内渲染的相机画面网格（彩色 / 深度可视化 / 语义）。它直接
读取游戏的共享 GPU 纹理——零拷贝、不影响游戏帧率。

用启动器的 **View Images** 按钮启动。游戏必须正在运行（查看器最多等
60 秒，超时提示你先开游戏）。

## 网格

- 网格 1–4 行 × 1–4 列，控制面板可调。
- **点击格子**循环切换该格显示的纹理；**悬停格子**出现下拉框按名字
  选择。
- 每格叠加显示纹理名与实时 FPS。
- `ESC` 退出。

## 可显示的模态

| 名字 | 内容 |
|---|---|
| `COLOR` | 相机彩色图 |
| `SEMANTIC` | 语义分割（每像素 = 其类别颜色，来自 `classes.json`） |
| `DEPTH_VIS` | 深度可视化，配色在 `custom_cameras.ini [depth_vis] CMAP` 配置 |

原始米制深度模态刻意不在本查看器显示——它属于 dump / ROS 消费端
（落盘深度格式见 [configs/recorder.md](configs/recorder.md)）。

## 2D 车辆框（B 键）

按 **B**（或勾选面板的 `Show 2D bbox`）叠加全部车辆的绿色 2D 边界框
——由 3D 真值投影而来，用来肉眼快速核对真值与画面的吻合度。

## 注意

- 相机拓扑变化（改过相机配置）自动跟进——无需重启。
- 日志在 `ac_simulator_suite\logs\`。
