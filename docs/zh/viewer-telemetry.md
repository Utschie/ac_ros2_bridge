# 遥测查看器（启动器：View Telemetry）

MoTeC 风格的实时遥测仪表盘 + 通道浏览器，直读游戏遥测数据。用启动器的
**View Telemetry** 按钮启动；游戏停在菜单里也能开，等游戏遥测就绪前
显示等待提示（每 0.5 秒重试；安装器已自动开启所需设置）。

## 仪表盘

- **顶部横幅**：LIVE 灯、状态、session、赛道 + 配置、车型、配胎、
  P 位 + 圈数、旗语、采样率、**Add plot** 按钮。
- **左列**：大字号档位 + 车速 + RPM 红区条；油门 / 刹车 / 离合 / 转向 /
  油量 / ERS 条；TC · ABS · DRS · PIT · 行车线指示灯；轮胎 2×2
  （芯温大字、内中外温色条、气压 / 寿命 / 盘温）；环境与车损。
- **右列**：CHANNELS 三面板堆叠（踏板 % / RPM / 车速）、轮胎温度面板
  （0–140 °C 刻度）、GG 图（自适应量程 + 当前点十字标）、圈速
  （当前 / 上圈 / 最快，差值着色 + 分段 + 罚时）、轮滑移 / 载荷 /
  轮速明细。
- **底部状态行**：共享内存连接态、包号、通道数、采样率。

## 通道浏览器（Add plot）

**Add plot** 新开一个浮动图窗（最多 8 个，可拖动/缩放，位置自动记忆）：

- 在过滤框输入关键字（如 `slip`、`tyreContact`、`cps.`），点击通道
  加入本图——每窗最多 8 条迹线、8 色循环且跨窗稳定。
- 通道**按单位自动分面板**：同单位通道共享一个真实量程面板；不同
  单位各占一个纵向面板、共享时间轴。想把同单位通道分开？再开一个
  图窗即可。
- 迹线默认画原始值（1-2-5 步长刻度、标注单位）；`normalized %` 勾选框
  可切换为每迹线各自归一的 0–100%。
- 全部 **194 个通道**都能画：`physics.*`（145——驾驶输入、运动、四轮
  14 项×4、ERS、环境等）、`gfx.*`（27——圈速、计时、排名、旗语、世界
  坐标等）、`cps.*`（22——自回正力矩、受载半径、传动系转速、气动
  系数、主销后倾、滑移角/率；需要套件自带的控制插件——未接入时图窗
  内有黄色提示）。

两个典型用途：抽查全链路（哪条通道不动就是没传出来），以及自组任意
通道组合的实时视图。同一份遥测也经 zenoh 发布（`ac/telemetry`、
`ac/timing`）并落盘为 `telemetry.jsonl`——见
[configs/recorder.md](configs/recorder.md)。

关窗用右上角 X（无 ESC 快捷键）。日志在 `ac_simulator_suiteogs`。
`ac_simulator_suite\logs\`。
