# 许可证激活

如何激活产品密钥、如何换密钥、以及激活失败时怎么办。

## 密钥从哪来

密钥由供应商发给你（一串短文本）。一把密钥绑定一台机器：首次激活时
密钥会记下你的机器码，之后该密钥只在这台机器上有效（换机时联系供应
商解绑/换发）。

## 激活

1. 启动启动器。未激活的安装上所有控件置灰，顶栏显示
   `License required to use AC Simulator Suite.`，唯一可用的按钮是
   **[Activate]**。
2. 点 **Activate**，粘贴密钥，确认。
3. 成功后全部解锁，顶栏常显 `License OK (<到期日>)`。

要把许可证迁到另一台机器，先联系供应商解绑密钥。

## 换密钥 / 续期

已激活时按钮变为 **[Change key]**——点它输入新密钥（续期或更换）。

## 诊断

一切许可证校验都记录在 `ac_simulator_suite\logs\license_dbg.log`
（请求与响应）。激活失败时：

1. 检查密钥有没有抄错（建议复制粘贴）。
2. 检查到服务器地址的网络/防火墙。
3. 看 `license_dbg.log` 最后几行——它会写明确切的 HTTP 错误。
4. 密钥已在别的机器用过会被服务器拒绝——联系供应商解绑。
