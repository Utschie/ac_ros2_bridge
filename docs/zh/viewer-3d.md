# 3D 查看器（启动器：3D View）

实时 3D 窗口：雷达点云 + 3D 真值车辆框。需要可选组件 **3D viewer**
（随套件安装）；要有点云还需雷达渲染器在跑（**Start Lidar（可随时点击——进入赛道后自动出图；本包起支持先启动后进游戏）**）且游戏
在 session 中。

## 你会看到

- **点云**：全部已启用雷达同显、每雷达独立显隐；着色为高度
  （turbo 彩虹）或回波强度（灰度）——面板切换；点大小滑块。
- **车辆真值框**：线框 OBB、带真实姿态——自车橙色、他车青蓝色。
- **自车三轴**——自车上三支箭头：**红 = 前、绿 = 左、蓝 = 上**
  （标准机器人约定，配色与 RViz 一致）。
- 默认浅色主题（`light bg` 勾选框切深色）；地面细线网格（1/2/5/10 m
  密度）高度跟随目标车所在路面（`grid follows target` 勾选框）；
  世界坐标轴。

## 相机操作

| 输入 | 动作 |
|---|---|
| 鼠标左键拖动 | 旋转 |
| 滚轮 | 缩放 |
| 中键拖动 | 平移 |
| **T** | 顶视图 |
| **G** | 地面网格开关 |
| Follow 列表（面板） | 选择跟随实体——默认自车；可跟任意一辆车；目标车消失自动回落自车 |
| 朝向跟随（勾选框） | 相机同时锁车辆航向 |

首帧数据到达时自动取景——不会一打开就"丢在旷野"。鼠标位于 ImGui
面板上时输入归面板、不动视角。

## HUD

面板显示 GPU 名、FPS、场景帧号、各雷达点数、无数据时的等待提示，
以及全部显示开关（`vsync` 默认开——在意延迟可取消）。关窗用右上角
X（无 ESC 快捷键）。

## 选卡

用启动器的 **3D viewer GPU 下拉**（`launcher.ini [viewer3d] ADAPTER`）。
不设 = 自动：在 NVIDIA 卡里优先选不接显示器的那块，让查看器跑在空闲
卡上。窗口布局记忆在 `configs\imgui_3dviewer.ini`。

日志在 `ac_simulator_suite\logs\`。
