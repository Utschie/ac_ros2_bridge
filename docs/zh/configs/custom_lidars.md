# custom_lidars.ini — 自定义雷达配置

定义套件模拟的雷达。**参数支持热重载（固态与旋转通用）**：保存 ini 约
1 秒生效，无需重启游戏或任何程序——在 3D 查看器里即时可见点云变化；
改参数、加雷达、删雷达、改段名均可（只用过 8 个不同雷达名后需重启雷达
渲染器复位）。注意：只修改扫描模式 CSV 本身不触发重载，需把 ini 也
保存一次。

## 坐标系

安装位置与朝向使用全套统一约定：**X 前、Y 左、Z 上**（见
[quickstart.md](../quickstart.md)）。朝前的雷达写 `FORWARD=1,0,0`；朝后的
写 `-1,0,0`。扫描模式 CSV 不受影响（方位角 0° = 传感器正前）。

参考车辆：保时捷 911 GT3 RS（992）——4572 × 1900 × 1322 mm
（半宽 0.95 m，车顶 z ≈ 1.32 m，后保险杠 x ≈ -2.8 m）。

## [LIDAR_<name>] — 每雷达一段

| 键 | 默认 | 说明 |
|---|---|---|
| `TYPE` | `solid` | `solid`（固态，模式来自 `SCAN_FILE`）或 `rotating`（360° 旋转多线，模式由参数生成）。 |
| `POSITION` | `0.4,0,1.1` | 安装位置 `x,y,z`（米，X 前 / Y 左 / Z 上）。 |
| `FORWARD` | `1,0,0` | 朝向；朝后写 `-1,0,0`。 |
| `SCAN_FILE` | *(固态必填)* | 扫描模式 CSV（列：#、方位角、俯仰角），相对本 ini 目录解析；随包模式在 `scan_mode\`。`rotating` 忽略。 |
| `SIM_HZ` | `10` | 每秒扫描帧数（`rotating` 即转速）。 |
| `NOISE` | `0` | 测距噪声标准差（米），模拟真实传感器的测距误差；0 = 干净数据。 |
| `RANGE_MIN` / `RANGE_MAX` | `0.5` / `200` | 量程（米）。 |
| `ENABLED` | `1` | 0 = 禁用该雷达。 |

## TYPE=rotating 的键（参数化扫描模式）

360° 扫描模式由参数生成——无需录制文件。每帧点数 =
`CHANNELS × COLUMNS_PER_REV`，点数过大时自动减列（保持整圈覆盖）。

| 键 | 默认 | 说明 |
|---|---|---|
| `CHANNELS` | `16` | 垂直线数（1–128）。 |
| `VERTICAL_ANGLES` | *(空)* | 逐线俯仰角表（度，逗号分隔），对应真实传感器的非均匀布线；数量须等于 `CHANNELS`。 |
| `VFOV_MIN` / `VFOV_MAX` | `-15` / `15` | 不写角度表时，线在 [MIN, MAX] 内均匀分布。 |
| `COLUMNS_PER_REV` | `1800` | 每圈列数（点火次数）——1800 = 0.2° 方位角分辨率。 |
| `ROT_DIR` | `cw` | 旋转方向（从上看）：`cw` = clockwise（顺时针）/ `ccw` = counter-clockwise（逆时针）。`cw` / `ccw`。 |
| `START_AZIMUTH` | `0` | 首列方位角（度）。 |

## 出厂配置

- `[LIDAR_front]` — 固态，车顶前缘朝前，10 Hz，0.5–200 m（启用）
- `[LIDAR_spin]` — 360° 旋转 32 线 × 0.2°，10 Hz（启用）
- `[LIDAR_rear]` — 车尾固态朝后，20 Hz（未启用）
- `[LIDAR_spin2]` — 360° 旋转 8 线非均匀角表示例（未启用）

未启用的段就是现成模板：设 `ENABLED=1` 后按上表调成你的传感器即可；要更多
雷达就加 `[LIDAR_*]` 段。
