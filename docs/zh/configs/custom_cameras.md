# custom_cameras.ini — 自定义相机配置

定义游戏插件每帧额外渲染的自定义相机。游戏启动时从
`ac_simulator_suite\configs\custom_cameras.ini` 加载一次；位姿与光学参数
支持保存即生效的热重载（见下文）。

解析是严格的：必填值缺失/非法会在启动时弹窗报错并禁用整个相机系统。
没有静默回退。

## 坐标系

安装位置与朝向使用全套统一约定：**X 前、Y 左、Z 上**（见
[quickstart.md](../quickstart.md)）。朝前的相机写 `FORWARD=1,0,0`；朝右的相机 y 取负、朝左取正。

参考车辆：保时捷 911 GT3 RS（992）——4572 × 1900 × 1322 mm
（半宽 0.95 m，车顶 z ≈ 1.32 m，后保险杠 x ≈ -2.8 m）。

## [render] — 渲染管线

| 键 | 默认 | 说明 |
|---|---|---|
| `PIPELINE` | *(必填)* | 渲染管线：`NATIVE_HDR`（独立渲染，更稳定；要求游戏内 HDR 开、运动模糊关）或 `YEBIS`（跟随游戏主画面后处理，游戏帧率低时偶发闪烁）。 |
| `EXPOSURE` | `1.0` | 曝光倍率（画面偏暗时调大，如 1.3）。 |

## [CAMERA_<name>] — 每相机一段

文件必须至少含一个 `[CAMERA_*]` 段，否则启动弹窗报错。

| 键 | 默认 | 说明 |
|---|---|---|
| `NAME` | *(必填)* | 相机唯一名字；其它配置按它选择本相机。 |
| `POSITION` | `0,0,0` | 安装位置 `x,y,z`（米，X 前 / Y 左 / Z 上）。 |
| `FORWARD` | `1,0,0` | 视线方向向量（车体系下的方向，朝前 = `1,0,0`）；朝后写 `-1,0,0`。 |
| `VERTICAL_FOV` | `60` | 垂直视场角（度）。 |
| `NEAR` / `FAR` | `0.05` / `2000` | 近/远裁剪面（米）——超出该范围的景物不会被渲染。 |
| `WIDTH` / `HEIGHT` | *(必填)* | 输出图像尺寸（像素）。 |
| `EMIT_COLOR` | `1` | 发布彩色模态。 |
| `EMIT_DEPTH` | `0` | 发布米制深度模态。 |
| `EMIT_DEPTH_VIS` | `0` | 发布深度可视化模态（配色在 `[depth_vis]` 设置）。 |
| `EMIT_SEMANTIC` | `0` | 发布语义分割模态。 |
| `ENABLED` | `1` | 0 = 跳过该相机。 |

## 热重载（保存即生效）

保存文件约 1 秒后，以下**五个参数**无需重启游戏即自动生效：

- `POSITION`、`FORWARD`、`VERTICAL_FOV`、`NEAR`、`FAR`

其余改动（`WIDTH`/`HEIGHT`、`PIPELINE`、`EMIT_*`、`ENABLED`、增删相机、
`[render]` 与 `[depth_vis]` 段）仍需重启游戏；保存时日志会提示哪些改动
未生效。

- 保存的文件有问题（非法值、相机重名等）时不会弹窗：日志记录原因，
  继续使用改动前的参数；改好后再次保存即可恢复。
- 修改 `VERTICAL_FOV`/`NEAR`/`FAR` 后，ROS 端的相机内参（camera_info）
  约数秒内自动更新。

## 深度可视化配色

`[depth_vis] CMAP` 选择深度可视化模态的配色：`inferno`（默认）或
`rainbow`。只影响屏幕显示；录制落盘的深度格式在 `recorder.ini` 配置
（见 [recorder.md](recorder.md)）。
