# capture_engine.ini — 游戏内采集引擎配置

游戏侧采集引擎的开关。**正常使用无需改动本文件**——出厂配置即已启用。
游戏启动时读取一次，修改后需重启游戏。

| 键 | 出厂值 | 说明 |
|---|---|---|
| `CAPTURE_ENABLED` | `1` | 生产总开关：关掉后游戏不产出任何数据——录制与实时转发双双停摆。 |
| `STREAM_ENABLED` | `1` | 实时转发开关：关掉后只影响 Linux/ROS2 实时流，本地录制不受影响。 |

提示：想"只录不转发"，改 `streamer.ini`（不写相机段）比关本开关更直接。
